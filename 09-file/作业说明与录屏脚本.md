# 09-file 文件上传作业说明与录屏脚本

## 一、实现思路说明（口语化，约 200 字）

这次做的是图片上传，用的是阿里云 OSS 的 SDK。先在 pom 里加了 aliyun-sdk-oss 依赖，然后把 endpoint、bucket、AccessKey 这些敏感配置单独放到 aliyun-oss.properties 里（这个文件加了 .gitignore 不提交），用 @PropertySource 加载，再通过 @ConfigurationProperties 绑定到 OssConfig 类，代码里直接注入就能用。上传逻辑在 OssServiceImpl：先查文件后缀在不在图片白名单里，不在直接拒掉；然后用 UUID 重命名防止重名互相覆盖；接着创建 OSS 客户端调 putObject 传上去，上传时按后缀设置 ContentType，这样浏览器打开链接直接显示图片而不是弹下载。返回的链接就是 bucket 名加 endpoint 加路径拼出来的。多图上传就是 Controller 用 MultipartFile 数组接、循环调单图上传；大小限制在 application.yml 的 multipart 里配了单文件 5MB、单次请求 20MB。Apifox 实测：传图返回 URL 能直接访问，传 txt 被拦截，超 5MB 返回 413。

## 二、实测结果（2026-11-04）

| 测试 | 请求 | 结果 |
|---|---|---|
| 单图上传 | POST /oss/upload，form-data file=图片 | ✅ 返回 `https://1st-yog.oss-cn-beijing.aliyuncs.com/img/<uuid>.png`，浏览器打开 HTTP 200 |
| 多图上传 | POST /oss/uploads，form-data 两个 files | ✅ 返回两个 URL 的数组 |
| 非图片拦截 | file=note.txt | ✅ 返回「上传失败：仅支持图片类型 jpg/jpeg/png/gif/bmp/webp」 |
| 超出限制 | file=6MB 假 png | ✅ HTTP 413（max-file-size: 5MB 生效） |
| OSS 查看 | OSS Browser 登录 AK | ✅ img/ 目录下能看到 UUID 命名的图片 |

> 桶 1st-yog 已设为**公共读**（原来是私有，且桶级「阻止公共访问」开着导致改不了，已关闭该开关后设置成功）。

## 四、Apifox 测试步骤（菜单级）

1. 打开 Apifox 客户端 → 进入项目 **backend-learning**
2. 左侧「**接口管理**」→ 顶部模块下拉框切到「**09-file**」（没有的话点下拉框旁刷新图标）
3. 看到 `POST /oss/upload 单图上传（OSS）` → 点开 → 右上角点「**运行**」标签
4. 「请求 Body」选 **form-data**：参数名 `file`，类型下拉选「**文件**」，值点「**选择文件**」→ 挑一张本地图片
5. 点「**发送**」→ 下方 Real 返回图片 URL → 复制丢进浏览器 → 图片显示
6. 左侧选 `POST /oss/uploads` → 运行 → form-data 加两行，参数名都填 `files`，类型都选文件 → 发送 → 返回 URL 数组
7. 拦截测试：回到 /oss/upload，把 file 换成一个 `.txt` → 发送 → 返回「上传失败：仅支持图片类型…」
8. 超限测试：file 选一个大于 5MB 的文件 → 发送 → 返回 413

> 若请求发送失败显示连接错误：检查后端是否在跑（IDEA 里运行 FileApplication，控制台看到 Tomcat started on port 8010）；「前置 URL」应为 `http://127.0.0.1:8010`。

## 五、OSS Browser 安装与查看步骤

1. 下载：https://github.com/aliyun/oss-browser/releases → 最新版 → `oss-browser-win32-x64.zip`（或官网 https://oss.browser.aliyun.com）
2. 解压到如 `D:\oss-browser`，双击 `oss-browser.exe`
3. 登录页：AccessKey / SecretKey 填自己的，Endpoint 选「**北京**」（或自定义填 `oss-cn-beijing.aliyuncs.com`）→ 登录
4. 左边点开 **1st-yog** → 进入 **img** 文件夹 → 看到上传的 UUID 图片，双击可预览，右上还能复制文件链接
